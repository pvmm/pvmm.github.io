# Pedro's Playground

A playground for testing things that run on the browser.

## Projects

- **Ace Editor** - Lightweight, embeddable code editor for JavaScript
- **WebMSX wasm2413 driver edition** - MSX emulator with a new YM2413 driver based on [emu2413](https://github.com/digital-sound-antiques/emu2413)

WebMSX was developed by Paulo Peccin, but this version has changes not created by the original author.
